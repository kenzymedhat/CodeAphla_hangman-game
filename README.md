# Python Hangman Game

Text-based Python Hangman game! Guess the hidden programming word one letter at a time. This project was built to practice foundational Python programming concepts.

## 🎮 Features

* **Randomized Gameplay:** Uses Python's built-in `random` module to select a secret word from a predefined list.
* **Life System:** Players are limited to 6 incorrect guesses before it's game over.
* **Input Validation:** Prevents the user from entering numbers, multiple letters at once, or guessing the same letter twice.
* **Replay Loop:** Once a game ends (win or lose), the player is prompted to play again without needing to restart the script.

## 🛠️ Concepts Used

This project demonstrates the use of core Python fundamentals:
* `while` and `for` loops
* `if-else` conditional statements
* String manipulation and formatting
* Lists (for tracking guessed letters)
* The `random` module
